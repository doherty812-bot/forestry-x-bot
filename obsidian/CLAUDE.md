# CLAUDE.md - 林業・薪販売事業経営ノート

## プロジェクト概要

**事業内容:** 新潟県における林業・薪販売事業

**経営規模:**
- 現在の管理面積: 1,500ha
- 目標管理面積: 3,000ha
- 主要樹種: 針葉樹（スギ、ヒノキ等）、広葉樹（コナラ等）
- 主力商品: 丸太販売、薪販売

---

## Obsidian ボルト用途

このボルトは以下の目的で使用します：

1. **森林経営計画の記録・管理**
   - 施業計画の策定・更新
   - 間伐・植林スケジュール
   - 地域別の経営状況

2. **丸太・薪の仕入れ・販売記録**
   - 取引先管理（仕入先、販売先）
   - 数量・価格・日付の記録
   - 在庫管理
   - 月次・四半期の売上集計

3. **顧客別の取引メモ**
   - 顧客情報（連絡先、取引条件）
   - 取引履歴と信用情報
   - 特記事項・要望事項

4. **地方創生・バイオマスエネルギー関連の情報整理**
   - 補助金・助成金制度
   - エネルギー利用動向
   - パートナーシップ・協力企業情報
   - 規制・法令情報

5. **経営戦略・AI活用の調査メモ**
   - 市場分析・競合調査
   - デジタル化戦略
   - AI・データ活用の検討
   - 長期経営ビジョン

## 主要なドメイン知識

### 樹種・丸太の分類
- **針葉樹**: スギ、ヒノキ、アカマツ等（建材用、チップ用）
- **広葉樹**: コナラ、クヌギ等（薪、炭用）
- **用途別**: 建材丸太、パルプ用丸太、薪、チップ

### 施業用語
- **間伐**: 雑木の除去で森を活性化
- **植林**: 新規植樹による再生
- **搬出**: 丸太を山から運び出す
- **スギ間伐**: スギ林の竹林化防止・保水力向上

### 取引単位
- **体積**: m³（立方メートル）
- **重量**: トン（t）
- **薪**: 束（たば）

### 新潟県の林業環境
- 豊富な杉・ヒノキ資源
- 豪雪地帯での操業制限（冬期）
- 地方創生・バイオマス関連の助成金活用機会

## カスタム要件

### 自動リンク提案ルール
**新規ノート作成時に以下を実施：**

1. **既存ノートの検索**: タイトルやタグから関連ノートを検索
2. **コンテキスト判定**: ノートの種類（顧客、取引、計画等）を自動判定
3. **wikilink 提案**: 関連する既存ノートへの `[[リンク]]` を提案
4. **テンプレート選択**: ノートの種類に応じたテンプレートを提案

**例：**
- "顧客A" という名前のノートを作成 → `[[顧客一覧]]` へのリンクを提案
- "2026-05-20 販売記録" → `[[2026-05-sales-log]]` へのリンクを提案
- "スギ間伐計画" → `[[annual-plan-2026]]` と `[[area-{該当地域}]]` へのリンクを提案

### 定期的な集計ノート
毎月自動生成を検討：
- `YYYY-MM-sales-summary.md`: 月別販売集計
- `YYYY-MM-inventory.md`: 月末在庫状況
- `YYYY-Q{n}-report.md`: 四半期経営レポート

### バックアップ・バージョン管理
- 重要な計画・取引記録は Git で定期バックアップ
- 月末に月次サマリーをロック状態で保存

## 議事録の管理ルール

### 保存場所・命名規則

- **フォルダ**: すべて `Meetings/` フォルダに保存
- **ファイル名**: `meeting-YYYY-MM-DD-相手先名.md` の形式
  - 例: `meeting-2026-05-19-yamada-lumber.md`
  - 相手先名は英字小文字 + ハイフン区切り

### テンプレート

- `Meetings/template-meeting.md` を参照
- 含まれる項目:
  - 日付・時間・場所
  - 参加者
  - 議題
  - 決定事項（テーブル形式）
  - 次回アクション（担当者・期限付き）
  - 関連ノートへのリンク

### 新規議事録作成時

**実施内容:**
1. 新規ノート作成時に自動で関連ノートを検索
2. 過去の関連議事録を検索
3. 相手先の顧客ノート（がある場合）にリンク
4. 以下の wikilink を自動提案：
   - `[[顧客-相手先名]]` - 相手先プロファイル
   - `[[過去の会議記録]]` - 直近の関連会議（あれば）
   - `[[進行中のプロジェクト]]` - 関連する進行中プロジェクト

**例:**
- 顧客「山田林業」との会議 → `[[顧客-山田林業]]` へのリンクを自動提案
- 「2026-05-25 新潟銀行との経営相談」 → 過去の融資相談記録があれば提案

### 議事録参照時の処理

「議事録を参照して...」と言われた場合：

1. **Meetings/ フォルダを検索**（Grep）
2. **キーワード別に過去議事録を抽出**
   - 相手先名で検索
   - 決定事項・アクション項目で検索
   - 日付範囲で検索

3. **要約を作成・提示**
   - 関連する過去の判断・約束を抽出
   - 進捗状況をまとめる
   - 次回会議への引継ぎ項目を列挙

**例:**
> 「山田林業との会議議事録を参照して」
> → Meetings/meeting-*.md を検索
> → 「山田林業」に関する過去5件の会議を抽出
> → 決定事項・アクション・進捗をサマリー

### 議事録の自動作成

ユーザーが「〇〇との会議をまとめて」と言った場合：

1. テンプレート（`Meetings/template-meeting.md`）から自動生成
2. ファイル名を `meeting-YYYY-MM-DD-相手先名.md` の形式で作成
3. 会話内容から以下を抽出：
   - 参加者
   - 議題
   - 決定事項
   - 次回アクション（担当者・期限）
4. 関連ノートへのリンクを自動提案

## 森林整備記録の管理ルール

### ⚠️ 年度表記ルール（重要）

**新潟県直接支援事業の特殊性：**

| 項目 | 内容 |
|------|------|
| PDF表示 | R6年度（予算枠関連） |
| 実際の申請年度 | 令和7年度 |
| **経営管理上の集計** | **令和7年度で統一** |

→ ファイル作成時も「R6」と表示される場合が多いが、経営管理上は「令和7年度」として記録・集計する

**参照**: [[R7-申請受領ステータス]]

### 保存場所・命名規則

- **フォルダ**: `ForestWork/` に保存
- **ファイル名**: `forestwork-R#-申請期-地域-施業内容-山主名.md`
  - 例: `forestwork-R6-3月期-村上-間伐更新伐保育.md`
  - 例: `forestwork-R6-秋期後期-村上-森林作業道-外野詰3号線-七湊堂ヶ沢.md`
  - 例: `forestwork-2026-05-19-yamada-thinning.md`（日付形式も許可）

### フォルダ分類

**ForestWork/ の3つのビュー:**

1. **ForestWork/山主別/** - 山主ごとに整備記録を整理
   - 山主名（個人 / 組合名）ごとのシンボリックリンク/インデックス
   - 同一山主の全施業記録の履歴確認に便利

2. **ForestWork/申請別/** - 申請先・申請期ごとに整理
   - 地域振興局ごと、申請期ごとの進捗確認
   - 申請期限管理に便利

3. **ForestWork/施業別/** - 施業内容別に整理
   - 施業タイプ別（間伐・下刈り等）の施業方法確認
   - 同じ施業タイプの過去事例確認に便利

## セカンドブレイン運用ルール

### パイプライン
- 0-raw/      : 投入口。生メモ・NotebookLMの回答を放り込む場所
- 1-desk/     : 作業机。処理後に片づける
- sources/    : PDF・原本。読み取り専用
- briefings/  : Claudeからの処理報告書
- Knowledge/  : 1アイデア1ファイルの恒久ノート
- Decisions/  : 判断・方針決定の記録
- Projects/   : 進行中プロジェクト状態
- ForestWork/ : 森林整備申請記録

### 最優先指令
sources/ か 0-raw/ の実在する出典に辿れないノートは書かない。
出典のない主張・補完・推測を書かない。絶対に。

### 処理ルール
1. 0-raw/ に素材が入ったら Knowledge/ にアトムを作る
2. 作る前に既存ノートを検索し、拡張できるなら拡張する
3. 各ノートは最低2つの関連ノートに [[wikiリンク]] で繋ぐ
4. 既存ノートと矛盾したら [FRICTION] ブロックを付けて指摘する
5. 処理済みの生メモは 0-raw/archive/ に移す
